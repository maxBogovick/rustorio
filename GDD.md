## Питч (одно предложение)
**Строй заводы из лент и машин на бесконечной сетке: добывай руду, превращай её в
детали, автоматизируй каждый шаг — и бесконечно улучшай свою фабрику.**

Жанр: 2D automation / factory (индустриальная тема). Тон: **уютный, без врагов и боя**.
Форма: **бесконечная песочница** (без экрана победы). Аудитория: любители систем,
логистики и оптимизации.

## Три столпа дизайна (через них проходит каждое решение)
1. **Автоматизируй всё.** Если действие повторяется — его можно построить машиной.
   *(Главный принцип Factorio.)*
2. **Всегда виден результат.** Предметы физически едут по лентам; любое улучшение
   заметно глазами сразу. Это же — наш принцип разработки: каждая веха играбельна.
3. **Просто и предсказуемо.** Понятные правила, никакого рандома: если что-то сломалось —
   есть причина, и вина игрока, а не кубик. Код тоже простой и расширяемый (см. `ARCHITECTURE.md`).

## Ядро-петля (что происходит минута-в-минуту)
```
  ┌─────────────────────────────────────────────────────────────┐
  │  вижу нехватку чего-то                                        │
  │        │                                                      │
  │        ▼                                                      │
  │  ставлю / переставляю здания  ──►  предметы едут по лентам    │
  │        ▲                                    │                 │
  │        │                                    ▼                 │
  │  оптимизирую  ◄──  вижу узкое место  ◄──  смотрю, как работает│
  └─────────────────────────────────────────────────────────────┘
        …и появляется новая нехватка → петля крутится дальше
```
Именно **прокручивание этой петли** и есть удовольствие
([Cook, «Loops and Arcs»](https://lostgarden.com/2012/04/30/loops-and-arcs/)):
ментальная модель → действие → обратная связь → обновлённая модель.

## Что игрок ЧУВСТВУЕТ (тройка удовольствия жанра)
- **проблема → решение → улучшение решения** — петля без конца;
- **видимый прогресс** — ленты быстрее, схемы чище, ratio сходятся;
- **предсказуемая сложность** — мир сложный, но объяснимый.
  ([Game Foundry, 2026](https://gamefoundry.games/blog/automation-games-explained-2026))

## Механики и здания
| Здание | Что делает | Статус |
|--------|-----------|--------|
| **Бур (Miner)** | стоит на руде, добывает её | ✅ есть |
| **Лента (Belt)** | везёт предмет на клетку вперёд | ✅ есть |
| **Печь (Furnace)** | руда → пластина (по времени) | ✅ есть |
| **Ящик (Chest)** | копит предметы | ✅ есть |
| **Сборщик (Assembler)** | пластина → шестерёнка | 🔜 M1 |
| **Развилка/подземка** | ветвление и пересечение лент | 🔜 M2 |
| **Лаборатория (Lab)** | тратит предметы → очки исследований | 🔜 M3 |

**Предметы:** руда, пластина, шестерёнка → далее по дереву исследований.
**Разнообразие — данными, а не кодом:** рецепты и апгрейды живут в таблицах
(см. `LESSONS.md`, Урок 8), поэтому контент растёт без разрастания кода.

## Прогрессия и цель (морковка бесконечной песочницы)
Победы нет — как в Factorio, где ракета лишь веха, а игра по сути бесконечна. Драйв дают:
1. **Дерево исследований:** переработанные предметы кормят Лабораторию → очки →
   открываются новые здания, рецепты и апгрейды (быстрее лента, быстрее печь…).
   Это расширяет *что ты вообще можешь построить*
   ([принцип Factorio](https://checkpointgaming.net/reviews/2020/08/factorio-review-fabrication-autmation-simulation/)).
2. **Самоставимые цели:** «выпускать N шестерёнок/мин», «переехать на новую руду»,
   «сделать схему компактнее». Счётчик производства/мин — на экране (M4).

## Вне рамок (сознательно НЕ делаем — защита от feature creep)
Самый большой риск — «раздуть» проект
([Rami Ismail](https://ltpf.ramiismail.com/prototypes-and-vertical-slice/)). Поэтому **пока нет**:
враги/оборона · жидкости и трубы · электричество · 3D · сюжетная кампания ·
мультиплеер · несколько карт/биомов. Всё это — потенциальные **расширения после**
готового ядра, а не фундамент.
