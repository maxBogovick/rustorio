# Rustorio 🦀🏭

Крошечная, но **настоящая** мини-Factorio на чистом Rust. Один зависимый крейт
([macroquad](https://macroquad.rs/)), компактный код с подробными комментариями, всё
компилируется за секунды и **сразу играется**. Задумана как учебный каркас: ты
дописываешь и развиваешь её, попутно понимая enum'ы, `match`, владение, заимствование
и модули.

> 📸 Скриншота пока нет — запусти `cargo run` и увидишь поле с бегущими по лентам
> предметами. (Хочешь — заскринь/сделай GIF и положи в `docs/`, а сюда добавь ссылку.)

> 🎓 **Новичок и хочешь понять всё с нуля?** Открой **[LESSONS.md](LESSONS.md)** —

## Запуск

```bash
cargo run          # окно откроется сразу
cargo run --release  # если захочешь пошустрее
```

## Как играть

1. Клавиша **1** — Бур. Поставь его (ЛКМ) на **синюю** клетку — там руда.
2. Клавиша **2** — Лента. **R** поворачивает. ЛКМ можно **держать** и вести линию.
   Веди ленту от бура — по ней поедут кружки руды.
3. Клавиша **3** — Печь. Приведи руду в неё — за пару секунд получится
   голубая пластина (полоска снизу = прогресс плавки).
4. Клавиша **4** — Ящик. Веди пластины лентой в него — там растёт счётчик.

**ПКМ** — снести здание. **Пробел** — пауза.

Полная цепочка: `Бур(на руде) → Лента → Печь → Лента → Ящик`.

## Карта проекта

> 📐 **Не знаешь, что делать и где?** Открой **[ARCHITECTURE.md](ARCHITECTURE.md)** —
> там карта, «золотое правило» и пошаговые рецепты. Ниже — краткая версия.

Проект разбит на маленькие файлы «по одной ответственности». Стрелки зависимостей
смотрят вниз (верхний слой знает про нижний, не наоборот):

| Файл | За что отвечает | Меняешь, когда… |
|------|-----------------|-----------------|
| `src/main.rs` | точка входа + игровой цикл `input→update→render` | почти никогда |
| `src/input.rs` | фаза 1: ввод → изменения мира | новая клавиша / действие мышью |
| `src/systems.rs` | фаза 2: шаг симуляции (тик мира) + тесты | новое правило мира |
| `src/render.rs` | фаза 3: отрисовка (только читает) | внешний вид, цвета, HUD |
| `src/game.rs` | состояние `Game` + фиксированный тик | глобальное состояние (счёт, режим) |
| `src/world.rs` | сетка клеток + `place`/`remove`/`neighbor` | структура мира |
| `src/building.rs` | `enum Building` + поведение здания | новое здание / его логика |
| `src/types.rs` | словарь: `Direction`, `Item`, `Tool` | новый предмет / инструмент |
| `src/config.rs` | ВСЕ настройки-числа | баланс, скорость, размер поля |

### Главная идея архитектуры

Здание — это `enum` со состоянием прямо внутри варианта:

```rust
pub enum Building {
    Miner   { dir, cooldown, output },
    Belt    { dir, item },
    Furnace { dir, input, progress, output },
    Chest   { items },
}
```

Логика раскидана по маленьким методам (`update`, `output`, `can_accept`, `accept`, …),
каждый — один `match` по этому enum'у. Когда добавишь новый вариант, **компилятор
сам покажет** все `match`, которые надо дополнить. Это и есть та самая «подсказка
компилятора», ради которой любят Rust.

### Как предметы едут по лентам (важный приём)

В `systems.rs`, функция `move_items`, передача идёт в две фазы: сначала мы
**собираем** список всех перемещений (только читая поле), потом **применяем** их. Так мы:
- обходим правило «нельзя одолжить две клетки `Vec` изменяемо одновременно»;
- получаем честную «одновременную» передачу без артефактов порядка.

Разберись с этими 30 строками — это лучший мини-урок по borrow checker'у здесь.

## Добавь своё здание (компилятор ведёт тебя за руку)

Полный рецепт — в [ARCHITECTURE.md](ARCHITECTURE.md#4-рецепты--пошагово--просто-иди-по-списку).
Коротко, на примере **Сборщика**:

1. `types.rs`: добавь `Item::Gear` и `Tool::Assembler`.
2. `building.rs`: добавь вариант `Building::Assembler { … }` — компилятор перечислит
   все `match`, где нужно дописать поведение. Иди по ошибкам сверху вниз.
3. `render.rs`: ветка в `draw_building` + цвет в `item_color`.
4. `input.rs`: клавиша **5** → `Tool::Assembler`.

## Идеи для прокачки (от простого к сложному)

- 🎨 **Плавное движение предметов**: рисуй кружок между клетками по `timer/TICK`.
- ⏪ **Отмена (undo)**: храни историю поставленных/снесённых зданий.
- 💾 **Сохранение/загрузка**: сериализуй поле (`serde` + JSON).
- 🔀 **Развилки лент**: лента отдаёт в первого свободного из нескольких соседей.
- 🧱 **Стопки предметов**: пусть лента/ящик хранят `(Item, u32)`, а не один слот.
- 🗺️ **Камера**: скролл и зум (сдвигай `OFFSET_*`, множь `TILE`).
- ⛏️ **Истощение руды**: у залежи конечный запас, бур его вычерпывает.
- 🤖 **Дерево крафта**: руда → пластина → шестерёнка → «наука» (как в Factorio).
- 🧪 **Тесты**: пара уже есть в `systems.rs`. Логика мира чистая — покрывай `#[test]`.
