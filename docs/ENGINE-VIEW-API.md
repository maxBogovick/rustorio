# Видео-API движка: что доступно логике без правок `render`

Справочник для написания уроков. Правило: чтобы что-то показать на экране, урок наполняет
данными `Overlay` в слое `game`. Слой `render` открывать не нужно — он рисует эти данные
обобщённо. Всё нейтрально к libGDX; `ArchitectureTest` это стережёт.

Точка наполнения — `GameState.prepareFrame(float delta)` (зовётся каждый кадр между вводом и
отрисовкой). Панели и подсветки пересобираются каждый кадр; тосты добавляются по событию.

## Канал 1 — панель (сводка; строки с иконками или без)

```java
// в GameState.prepareFrame или где угодно в game:
List<PanelRow> rows = List.of(
        PanelRow.of(Item.IRON_PLATE, "128"),   // иконка предмета + текст
        PanelRow.of(Item.GEAR, "64"),
        PanelRow.text("итого: 192"));           // строка без иконки
overlay.panel(new HudPanel("Производство", rows, Corner.TOP_RIGHT));
```

Углы: `TOP_LEFT`, `TOP_RIGHT`, `BOTTOM_LEFT`, `BOTTOM_RIGHT`. Несколько панелей в одном углу
складываются столбиком.

## Канал 2 — подсветка клетки

```java
overlay.highlight(x, y, Tint.SELECT);   // закрасить клетку смысловым цветом
```

Смыслы `Tint`: `NEUTRAL`, `GOOD`, `WARN`, `BAD`, `SELECT`, `RANGE`, `GHOST`. Годится для
выделения, радиуса действия, превью чертежа, тепловых карт (набор клеток разного `Tint`).

## Канал 3 — метка над клеткой (текст в мире)

```java
overlay.label(x, y, "нет сырья", Tint.BAD);   // плавающий текст над клеткой, едет с картой
```

В отличие от панели (прибита к углу окна), метка живёт в мировых координатах.

## Канал 4 — линия-связь между клетками

```java
overlay.line(x1, y1, x2, y2, Tint.GHOST);   // линия между центрами клеток
```

Для сетей (логистика, сигналы), потоков, подсказок «это кормит то».

## Канал 5 — уведомление (тост)

```java
overlay.toast("Изучено: Быстрые ленты");   // живёт несколько секунд, затухает
```

Событийный канал: добавляется в момент события (из `game` или `input`), стареет сам.

## Доступ

- `GameState.overlay()` — объект `Overlay` (читает `render`, наполняет `game`).
- `GameState.prepareFrame(delta)` — пересборка кадра; уже вызывается в `GameScreen`.

## Живые примеры в коде

| Что | Где наполняется | Канал |
|-----|-----------------|-------|
| Панель «Производство» с иконками (данные D2) | `GameState.prepareFrame` | панель |
| Клетка-получатель под курсором | `GameState.prepareFrame` | подсветка |
| Имя здания под курсором | `GameState.prepareFrame` | метка |
| Линия «здание → получатель» | `GameState.prepareFrame` | линия |
| «Изучено: …» при исследовании | `InputHandler` | тост |

## Когда всё-таки открывать `render`

Только при добавлении **нового ВИДА** визуала, которого нет среди трёх каналов (например,
линия между клетками, мини-карта, график). Тогда: новый record в `game/view` + ветка
отрисовки в `render/OverlayRenderer` (+ при нужде цвет в `render/Palette`). Для обычной
фичи-урока этого не требуется.
