## 4. Где что лежит в коде

```
core/     Config (константы) · Balance (изменяемый баланс) · TickContext
          Item · Tool · Direction · Tech · Effect
model/    World (фасад) · Chunk · OreMap · Tile · Cell
          sealed Building: Miner · Belt · Furnace · Chest · Assembler
                           Splitter · UndergroundBelt · Lab
          BeltSegment · BeltNetwork · BeltView   ← транспортные линии
          Recipe · Technology · ProcessKernel    ← контент как ДАННЫЕ
sim/      Simulation — конвейер фаз одного тика
game/     GameState (фикс. тик) · Research (очки и технологии)
render/   Renderer · Textures        input/  InputHandler        screen/ GameScreen
bench/    SimulationBenchmark
```

**Два приёма, которые проходят через весь проект** — если увидите их нарушение, это баг:

1. **Контент — это данные.** Новый рецепт или технология = **строка в таблице**, не код.
2. **Делать неправильное невозможно.** `drain` вместо геттера, проверка внутри `research()`,
   штамп тика вместо ручного сброса — везде, где ошибку можно исключить по конструкции, она
   исключена.

## 5. Команды

```bash
./gradlew run         # запустить игру
./gradlew test        # все тесты (56 штук)
./gradlew benchmark   # сколько миллисекунд занимает шаг симуляции
```

### Управление в игре

| Клавиши | Действие |
|---------|----------|
| `1`–`8` | выбрать здание (бур, лента, печь, ящик, сборщик, развилка, подземка, лаборатория) |
| `ЛКМ` / `ПКМ` | поставить / снести (ЛКМ можно держать и вести линию) |
| `R` | повернуть |
| `Пробел` | пауза |
| `F1`–`F4` | открыть технологию (если хватает очков) |

### Что попробовать в первую очередь

1. Поставьте бур на синюю руду, протяните от него **длинную ленту без ящика в конце** — она
   упрётся в тупик и забьётся **по два предмета на клетку**, а предметы поедут **плавно**.
2. Снесите клетку в середине забитой ленты — линия разрежется, груз с этой клетки исчезнет.
3. Соберите цепочку `бур → печь → сборщик → лаборатория` и посмотрите, как на лаборатории
   растут очки. Наберёте 10 — жмите `F1`, лента поедет быстрее.

## 6. Правила, которые экономят нервы

- **Один файл — один хозяин.** Карта владения — в [TASKS.md](../TASKS.md) §4. Нужна правка в
  чужом файле — пишете владельцу, а не лезете сами.
- **Чужой тест уронили — не чините сами.** Красный чужой тест значит, что вы изменили
  поведение, на которое кто-то рассчитывает. Разбирайтесь вдвоём.
- **`build.gradle` — общий.** Правится **отдельным маленьким PR**: конфликт в сборочном файле
  останавливает всю команду.
- **Тест, который вы не видели красным, — не тест.** Ломайте специально, проверяйте, что
  поймали, откатывайте.
