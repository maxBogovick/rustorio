# Урок 2 — Бур на карте: кликни на руду

В уроке 1 бур был классом, который тикал в консоли. Теперь у нас есть окно с картой и рудными
областями. Пора соединить одно с другим: **кликаешь по руде — на клетке появляется бур**. По
траве кликнешь — ничего: бур ставится только на руду.

Это первый по-настоящему игровой шаг: мышь → клетка мира → здание на карте. Разберём его по
кусочкам — мир, клик, отрисовка, связка.

---

## 1. Мир, который держит буры

Чтобы буры где-то «жили», заведём минимальный мир. Он знает две вещи: где руда (спрашивает у
`OreMap` из прошлого шага) и какие буры уже поставлены.

```java
// com/rustorio/World.java (суть)
public final class World {
    private final Map<Long, Miner> miners = new HashMap<>();   // клетка → бур

    public boolean hasOre(int x, int y) { return OreMap.hasOre(x, y); }
    public boolean hasMiner(int x, int y) { return miners.containsKey(key(x, y)); }

    /** Поставить бур, если клетка в поле, на руде и ещё свободна. */
    public void placeMiner(int x, int y) {
        if (inBounds(x, y) && hasOre(x, y) && !hasMiner(x, y)) {
            miners.put(key(x, y), new Miner());
        }
    }

    /** Один шаг мира: каждый бур проживает свой тик. */
    public void tick() {
        for (Miner miner : miners.values()) miner.tick();
    }
}
```

Здесь важен один принцип: **правило «где можно строить» живёт в МИРЕ, а не во вводе.** Ввод
(клик мышью) не решает, можно ли тут ставить бур, — он лишь говорит миру «игрок ткнул сюда».
Ставить или нет (на руде? свободно?) решает `placeMiner`. Так рядом с миром собраны все правила
о нём, а не размазаны по обработчику мыши.

Буры храним в карте «клетка → бур», а не в двумерном массиве: поле большое, а занятых клеток
мало — карта тратит память только на реально поставленное.

---

## 2. От клика до клетки

Мышь живёт в пикселях окна, а бур ставится в клетку МИРА. Перевести одно в другое может только
камера — она знает, куда смотрит окно и с каким зумом. Даём ей метод `pickTile`:

```java
// GameCamera
public TilePos pickTile(float screenX, float screenY) {
    unproject(screenX, screenY);                       // пиксель окна → точка мира
    int gx = (int) Math.floor(tmp.x / GfxConfig.TILE);
    int gy = gridH - 1 - (int) Math.floor(tmp.y / GfxConfig.TILE);  // Y мира растёт вверх
    return new TilePos(gx, gy);
}
```

А ввод на нажатие левой кнопки берёт клетку под курсором и передаёт миру:

```java
// InputHandler.handle(World world, float delta)
if (Gdx.input.isButtonJustPressed(Input.Buttons.LEFT)) {
    TilePos tile = camera.pickTile(Gdx.input.getX(), Gdx.input.getY());
    world.placeMiner(tile.x(), tile.y());              // мир сам решит, можно ли
}
```

`isButtonJustPressed` — ловим МОМЕНТ нажатия, а не «кнопка зажата»: один клик — один бур.

---

## 3. Нарисовать бур

Спрайт бура в атласе уже есть (`Textures.miner`). Слой `BuildingRenderer` до сих пор был пустым
каркасом — теперь наполним его: спросим у мира, где стоят буры, и нарисуем спрайт в каждой такой
клетке.

```java
// BuildingRenderer
void render(World world) {
    float tile = GfxConfig.TILE;
    batch.begin();
    world.forEachMiner((x, y) ->
            batch.draw(textures.miner[0], grid.x(x), grid.yBottom(y), tile, tile));
    batch.end();
}
```

`grid.x/yBottom` переводят клетку в мировые пиксели (и делают Y-flip: модель считает строки
сверху, а libGDX рисует снизу вверх). Графика по-прежнему просто ЧИТАЕТ мир и рисует — ничего в
нём не меняя.

---

## 4. Связка: ввод → тик → рендер

Экран держит мир и каждый кадр гоняет три фазы:

```java
// GameScreen.render(float delta)
input.handle(world, delta);      // 1. ввод: камера + постройка бура кликом
world.tick();                    // 2. тик: буры делают свою работу
renderer.render(world, delta);   // 3. рендер: карта + буры
```

Три расцепленные фазы — сердце любой такой игры: сначала намерения игрока меняют мир, потом мир
проживает шаг, потом мы его рисуем. Каждая фаза знает про мир, но не лезет в чужую работу.

---

## 5. Запуск

```
./gradlew run
```

На карте — рудные области (синим). **Кликни по синей руде** — появится бур. **Кликни по серой
траве** — ничего: `placeMiner` не пустит. Поставь несколько, поводи камерой (WASD/колесо/средняя
кнопка) к дальним залежам и поставь буры и там.

Честно: бур сейчас копает «в никуда» — руду он добывает (в `tick`), но нести её ещё нечем. Ленты
и ящик, которые подхватят добычу, — следующие уроки. Сейчас мы «додавили» именно бур: он стал
настоящим зданием на карте, которое ставят по правилам мира.
