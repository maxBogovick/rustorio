          A Kind is just a named recipe pool — declare one here ONLY if you want several different buildings to deliberately share the exact same set of recipes. Most buildings don't need this at all: leaving a building's own "Recipe kind" (Buildings tab) as "— private —" already gives it an isolated pool with zero setup. Once declared, this kind's own path shows up as a pickable option on both the Recipes and Buildings forms. This list also shows every building's own private pool that's actually in use (like a FURNACE-family building's default id) — click one to see what points at it, even though it has no separate file to edit here.
